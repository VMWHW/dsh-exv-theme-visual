# dsh-exv-theme-visual

EXV 主题的可选**视觉**增强包。命名规则：视觉增强用 `-visual`，功能增强用 `-function`。

1.0.0 起不再限制体积与性能——这个包就是给「显卡有富余」的机器准备的。

## 现在有什么

- **实时渲染开场动画（2K / 4K 可选）**：不播视频，每一帧现算；2K = 2560×1440、4K = 3840×2160，按 16:9 缩放铺进窗口。接管基座的开场动画（基座「其他 / 开场动画」关掉时本包不接管）。
- **无极调色**：色相 / 饱和度 / 明度三根滑条算出主色写回 `theme.accent`，接管基座那 6 张色卡；和基座一样，重启 DSH 后生效。
- **六盏后效灯**：色差 / 溢光 / 颗粒 / CRT / 光晕 / 暗角，按这个固定顺序叠加，作用范围是整个窗口（含文字）。
  - 色差：整页 RGB 通道拆分，R 右移、G 不动、B 左移；
  - 溢光：窗口四边一圈主色柔光；
  - 颗粒 / CRT：整窗覆盖层；暗角只盖在背景层上；
  - 光晕：给原生带发光的控件画横向镜头拉丝（「框」类容器只画上下两条边光）。
- **超高清背景卡**：六张 Battlefield 3 原图（3840 宽，未裁切）的 WebP，按「相机」模型缩放与平移——最小 100% 就是短边填满，任何取值都看不到图片边界；背景按文件夹归类。
- **出厂预设**：两条带调色的增强包预设（大毁灭者、线性推进），注入基座的预设列表，带「视觉+」角标；应用时自动打开无极调色。
- **安全回退**：整页后效有黑屏风险，所以开色差时会写一个 armed 标记，只有在「界面还能操作」时撤销；下次启动若发现上次没画出来，自动熄灭全部效果灯并给一行提示。

配置存在 `localStorage['dsh-exv-visual.config.v1']`。

## 安装

- 客户端「插件 → 添加插件」填 `dsh-exv-theme-visual`，或命令行 `dsh plugin --profile desktop add dsh-exv-theme-visual`；
- 也可以装本体 Release 里的单文件安装器（Setup.exe），勾上「视觉增强包」。

## 构建

`client.js` 由本机脚本 `_work/_visual-client.cjs` 生成：它从基座 `cyan-theme/client.js` 里抽出开场动画的同一份代码与数据，再叠加后效层、调色、背景与预设注册。**不要手改这个 10MB 的产物**，改生成器再重跑。
